# Oğuzhan Özdemir — portfolio mirror

This repository contains the generated static mirror of
[Oğuzhan Özdemir's portfolio](https://oguzhan-ozdemir.vercel.app/). The Vercel
deployment is the primary production site.

The authored source, build configuration and validation suite live in the
private `ossan-port` repository. Every push to its main branch runs the tests,
production build and performance checks before publishing this mirror. Changes
to the generated HTML, CSS or image files here will be replaced by the next
verified deployment.
